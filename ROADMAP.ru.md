# Дорожная карта

[English version](ROADMAP.md)

Дорожная карта отражает общее направление. Приоритеты могут меняться с учётом
опыта использования в реальных Laravel-приложениях и обратной связи сообщества.

## 0.1 — Основа безопасного сбора

- [x] включаемый сбор неудачных HTTP-запросов
- [x] рекурсивное скрытие секретов и зашифрованное локальное хранение
- [x] ограничение срока хранения и количества файлов, атомарная запись
- [x] Artisan-команды для просмотра, повтора, создания теста и удаления
- [x] матрица совместимости с Laravel 12–13

## 0.2 — Более детерминированный повтор HTTP-запросов

- [ ] имитация сохранённых исходящих вызовов Laravel HTTP Client
- [ ] более подробный отчёт о различиях сохранённого и повторного ответов
- [ ] подключаемые хранилища снимков
- [ ] пользовательские сборщики метаданных

## 0.3 — Адаптеры состояния приложения

- [ ] явные, подключаемые адаптеры фикстур базы данных
- [ ] адаптеры feature flags и состояния кеша
- [ ] сохранение заданий очереди и событий
- [ ] миграции схемы снимков и инструменты совместимости

## До версии 1.0

- [ ] внешний аудит безопасности
- [ ] тесты производительности и параллельной работы
- [ ] документированная политика совместимости снимков
- [ ] обратная связь от нескольких реальных production-приложений

Есть сценарий, который должен изменить порядок задач? Создайте GitHub Discussion.
