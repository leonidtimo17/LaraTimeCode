# Участие в разработке

[English version](CONTRIBUTING.md)

Спасибо, что помогаете улучшать LaraTimeCode.

## Перед созданием issue

- Проверьте существующие issues и discussions.
- Используйте форму сообщения об ошибке для воспроизводимых дефектов.
- Никогда не прикладывайте настоящий снимок `.repro`, не проверив и не очистив его.
- Для проблем безопасности используйте приватную отправку отчёта об уязвимости на GitHub.

## Локальная установка

```bash
git clone https://github.com/leonidtimo17/LaraTimeCode.git
cd LaraTimeCode
composer install
composer check
```

## Pull requests

1. Делайте изменения сфокусированными и объясняйте решаемую пользовательскую проблему.
2. Добавляйте или обновляйте тесты при изменении поведения.
3. Выполните `composer check`.
4. При изменении поведения обновите раздел `Unreleased` в `CHANGELOG.md`.
5. Не нарушайте совместимость с поддерживаемыми версиями PHP и Laravel.

Участвуя в проекте, вы соглашаетесь соблюдать [Кодекс поведения](CODE_OF_CONDUCT.ru.md).
