# Support

Use [GitHub Discussions](https://github.com/leonidtimo17/LaraTimeCode/discussions)
for usage questions and design ideas.

Use [GitHub Issues](https://github.com/leonidtimo17/LaraTimeCode/issues) for

production snapshots through public issues or discussions.
