# Политика безопасности

[English version](SECURITY.md)

## Поддерживаемые версии

Пока LaraTimeCode не достиг стабильного релиза, исправления безопасности
выпускаются только для последней опубликованной версии.

## Сообщение об уязвимости

Не создавайте публичный issue и не прикладывайте production-файлы `.repro`.

Используйте кнопку **Report a vulnerability** на вкладке Security репозитория
GitHub. Если приватная отправка отчётов недоступна, напишите на
`leonidtimo17@gmail.com` с темой `LaraTimeCode security report`.

Укажите затронутую версию, возможные последствия, шаги воспроизведения и
минимальный очищенный пример. Подтверждение получения должно прийти в течение
семи дней.

## Работа со снимками

Считайте каждый снимок потенциально конфиденциальным даже после скрытия секретов:

- не отключайте шифрование за пределами локальной среды разработки;
- ограничьте доступ к `storage/laratimecode`;
- задавайте небольшой срок хранения;
- проверяйте снимки перед отправкой другим людям;
- удаляйте снимки после завершения исследования.
